# 🚀 Lucky's Cydia Repo

Welcome to **Lucky's Cydia Repo**! This is a custom Cydia repository hosted via GitHub Pages, built to host custom tweaks, fixes, and packages for classic iOS devices.

---

### ⚠️ Repo Status: BETA
> **Note:** This repository is currently in **active beta development**. Things are constantly being added, tested, and updated. Expect frequent changes!

---

### 📲 How to Add This Repo to Cydia

1. Open **Cydia** on your jailbroken iOS device.
2. Go to the **Sources** tab at the bottom.
3. Tap **Edit** (top right) $\rightarrow$ **Add** (top left).
4. Enter the following URL:
   ```text
   http://lachie-kid.github.io/Lucky-s-cydia-repo/
